# Fast Reopen

![Fast Reopen](https://raw.githubusercontent.com/vipinsight/fast-reopen/master/src/logo64.png?raw=true "Fast Reopen")

Keep running your browser in background for faster reopening. This extension doesn't access any user data and contains no code: it only requests the browser's `background` permission.

## Install

[Get Fast Reopen from the Microsoft Edge Add-ons store](https://microsoftedge.microsoft.com/addons/detail/gpkgfiklomfbkdlkinanbfgcjdeodgff).
